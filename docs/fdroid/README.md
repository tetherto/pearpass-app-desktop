# F-Droid workstream (Android)

This repository (`pearpass-app-desktop`) does not include an Android Gradle project. The PearPass Android app is developed in the mobile repository:

* `https://github.com/tetherto/pearpass-app-mobile`

All F-Droid readiness work (flavor/channel isolation, version-check behavior, GMS credentials gating, fdroiddata recipe) must be implemented against that mobile repo.

This repo is used to keep an append-only execution log (`progress.txt`) and durable agent learnings (`AGENTS.md`) for the F-Droid workstream.
